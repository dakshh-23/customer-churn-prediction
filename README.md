# Customer Churn Prediction Using Machine Learning

## 1. Project Overview
Customer churn occurs when customers stop using a company's products or services. This project aims to analyze customer churn patterns using Python and explore how machine learning can help identify customers who may be likely to leave a service.

## 2. Problem Statement
Businesses may lose customers without understanding the reasons behind their decisions. The goal of this project is to analyze customer information, identify factors associated with churn, and plan a machine learning approach to predict potential customer churn.

## 3. Project Objectives
- Analyze customer churn patterns.
- Identify factors associated with customer churn.
- Perform data cleaning and exploratory data analysis (EDA).
- Visualize important trends using Python.
- Develop a baseline machine learning classification model in a later phase.
- Evaluate the model using appropriate performance metrics.

## 4. Dataset
**Dataset Name:** IBM Telco Customer Churn

**Dataset Source:** [Kaggle – Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

The dataset contains customer-related information such as tenure, contract type, payment method, monthly charges, services, and churn status.
